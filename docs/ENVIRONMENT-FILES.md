# Local environment configuration

Runtime environment files are intentionally excluded from Git by owner instruction (2026-10-15). Existing local files are preserved. Provision values through the deployment secret store or your local environment; never paste credentials into source or reports.

## Configuration keys

These are variable names only, collected from existing example files. Values are deliberately omitted.
